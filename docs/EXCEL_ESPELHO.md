# Excel Espelho para Auditoria — V13

A exportação Excel do Solocontrol Lab é uma representação **editável** do relatório oficial.

- A aba **Relatório Oficial** é construída com células, mesclagens, bordas e fórmulas — não é uma captura/print do PDF.
- Os valores calculados são vinculados às abas técnicas por fórmulas.
- As abas técnicas preservam dados de entrada e memória de cálculo para auditoria.
- O gráfico granulométrico é incorporado como elemento visual; os dados e cálculos que o alimentam permanecem em células na aba Granulometria.
- O relatório mantém paginação A4, identidade Solocontrol, número/revisão, responsáveis e conclusão.
- O Excel é complementar ao PDF oficial e deve ser arquivado junto à emissão quando necessário para rastreabilidade.
