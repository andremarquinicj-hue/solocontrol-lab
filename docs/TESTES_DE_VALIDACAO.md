# Testes de validação rápida

Antes de colocar o sistema em produção, use estes cenários conhecidos para confirmar cálculo, faixa e gráfico.

## Cenário A — Padrão A conforme

Massa inicial A1 = 40.000 g  
Massa inicial A2 = 40.000 g  
Fundo A1 = 0 g  
Fundo A2 = 0 g

| Peneira | Peso A1 | Peso A2 |
|---|---:|---:|
| 2½" / 63,5 mm | 0 | 0 |
| 2" / 50,8 mm | 2.000 | 2.000 |
| 1½" / 38 mm | 18.000 | 18.000 |
| 1" / 25,4 mm | 16.000 | 16.000 |
| ½" / 12,5 mm | 4.000 | 4.000 |

Resultado esperado de retida acumulada: **0 / 5 / 50 / 90 / 100%**.  
Resultado geral esperado: **CONFORME**.

## O que conferir no PDF

- logo nítida;
- cabeçalho completo;
- apenas peneiras do padrão escolhido na tabela;
- gráfico com eixo X logarítmico;
- peneiras no topo;
- diâmetro em mm embaixo;
- % passante no eixo esquerdo;
- % retida no eixo direito;
- curva azul dentro da faixa vermelha no cenário conforme;
- notas e rodapé;
- nome do responsável pelo ensaio;
- responsável técnico e CREA;
- uma única página A4 sem corte.
